# Prac-Times

## Что это
Мой личный учебный проект новостного сайта, заточенного под политику и бизнес в мире. Хочу научиться загружать данные с API, обрабатывать полученный результат, выводить его на страницу, авторизации и множеству других фич фронтенд-разработки, а также улучшить своё понимание архитектуры подобных проектов в целом.

## Stack
- React
- TypeScript
- CSS Modules
- React Router
- React Redux



## Структура

### assets/
Вспомогательные материалы для дизайна самого сайта.

### components/
Переиспользуемые(дай бох) компоненты сайта.

### data/
Данные, которые используются эмулятором backend.

### hooks/
Кастомные хуки.

### pages/
Отдельные страницы сайта.

### store/
Хранилище состояний и функции React Redux.

### styles/
Общие стили сайта(Шрифты, обнуление, цвета).

### types/
Общие TypeScript-типы, стоящие вынесения в отдельную папку.

### ui/
Переиспользуемые микро-компоненты(Кнопки, заголовки, тэги и т.д)

### utils/
Вспомогательные функции.



## Данных

Эмулирую бэкенд с вымышленными данными через Mockoon.

ВАЖНО: Не создаю собственный сервер и не пытаюсь стать полноценным full-stack просто на ровном месте. Занимаюсь этой эмуляцией РОВНО до той степени, которая нужна для проверки работоспособности проекта.
